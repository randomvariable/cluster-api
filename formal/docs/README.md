# formal/ documentation index — Diataxis

Documentation for the Cluster API formal-modelling subtree, organised
per the [Diataxis](https://diataxis.fr) framework.

| Type | Audience | When to read |
|---|---|---|
| [tutorial.md](./tutorial.md) | First-time reviewer | Learning what the corpus is and reproducing a verdict end-to-end. |
| [how-to.md](./how-to.md) | Returning operator | Goal-oriented recipes — "I want to verify FM-X", "I want to add a new failure mode". |
| [reference.md](./reference.md) | Spec reader | Exhaustive listing of make targets, state variables, actions, contract obligations. |
| [explanation.md](./explanation.md) | Architecture reviewer | Why the corpus is shaped the way it is — design choices, trade-offs, what's deferred. |

For LLM agents: [AGENTS.md](./AGENTS.md) gives a structured machine-
readable summary covering the same material.

For the rationale behind the corpus, the [CAEP](../../docs/proposals/20260507-formal-control-plane-lifecycle-model.md)
is the architectural source of truth.
